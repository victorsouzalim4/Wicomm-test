# Etapa 4 — Mobile (responsividade)

## Objetivo

Fazer a página funcionar bem no celular, no tablet e no computador. Esse é o critério "Responsividade" (peso 15).

## Abordagem: mobile-first

Os estilos base são os do celular. Tablet e desktop entram com `min-width`, usando o mixin `respond-to()` da [parte 1.2](../etapa-01-stack/02-configurar-sass.md). Assim o celular carrega o CSS mais simples e as telas maiores só adicionam regras.

## Se o Figma não tiver versão mobile

Cada decisão de adaptação (o que empilha, o que vira carrossel, o que vira menu hamburguer) é nossa, e **cada uma vai para o README**, como o teste pede.
