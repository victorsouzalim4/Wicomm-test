# 4.4 — Grids e vitrines

## Proposta

- Usar CSS Grid com colunas por breakpoint, por exemplo: 1 ou 2 no celular, 2 ou 3 no tablet e o número do Figma no desktop.
- Seções lado a lado no desktop (texto + imagem, por exemplo) ficam **empilhadas** no celular.
- Footer: colunas de links viram **acordeão** no celular (`<details>`/`<summary>`, que já é acessível nativamente).

## Passos

- [ ] Revisar seção por seção como cada uma fica no celular e no tablet
- [ ] Registrar no README cada adaptação que não estiver no Figma

## Commits sugeridos

- `style: adapta vitrines e grids para celular e tablet`
- `feat: transforma colunas do footer em acordeão no celular`
