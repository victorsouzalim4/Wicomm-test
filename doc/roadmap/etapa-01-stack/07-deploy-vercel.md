# 1.7 — Fazer o primeiro deploy na Vercel

## Objetivo

Publicar a página em branco logo no começo, para validar o caminho até a produção antes de ter código importante.

## Passos

- [ ] Criar o repositório **público** no GitHub e fazer o push da `main`
- [ ] Na Vercel, importar o repositório. O preset **Vite** é detectado sozinho, com build `npm run build` e saída `dist`.
- [ ] Conferir se a URL publicada abre a página
- [ ] Colocar o link da página publicada no README

## Pronto quando

Cada push na `main` gera um deploy automático e o link funciona.

## Commits sugeridos

- `docs: adiciona link do deploy no README`
