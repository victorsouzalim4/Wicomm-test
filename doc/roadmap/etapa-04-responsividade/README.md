# Etapa 4 — Mobile e responsividade

## Objetivo

Garantir que a página funcione bem no computador, no tablet e no celular (critério "Responsividade", peso 15). Também registrar as decisões sobre o que o Figma não mostra.

## Estratégia

- **Mobile-first:** o CSS base é o do celular, e os `@media (min-width: ...)` adicionam o layout maior. O código fica mais simples e o celular baixa menos CSS.
- **As decisões são desta etapa, mas a aplicação acontece em cada componente.** Os breakpoints e os padrões definidos aqui já valem na hora de construir os componentes, para não precisar refazer tudo no fim.
- **Se o Figma só tiver o desktop**, as versões tablet e mobile são decisões nossas e precisam ir para o README com o motivo, como o teste pede.
