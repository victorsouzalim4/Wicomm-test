# 5.3 — Verificação final da página publicada

## Objetivo

Conferir a página publicada como o avaliador vai ver, antes de enviar o e-mail.

## Passos

- [ ] Abrir o link da Vercel numa janela anônima (sem cache e sem o carrinho salvo)
- [ ] Testar o fluxo completo: adicionar produto, abrir o mini cart, alterar a quantidade, remover, recarregar a página e conferir se o carrinho continua
- [ ] Testar no celular de verdade
- [ ] Rodar o Lighthouse (mobile e desktop) e anotar as notas no README
- [ ] Conferir se nenhuma imagem quebrou (aba Network, filtro "Img")
- [ ] Conferir se o repositório está **público** e se o README tem os dois links (repositório e página)

## Pronto quando

O link funciona numa janela anônima, no celular e no computador, e o README está completo.
